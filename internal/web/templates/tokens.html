Using a token

curl -H "Authorization: Bearer $RELATA_TOKEN" \
  '{{"https://your-host/api/v1/search?q=delivery"}}'

Send it in the Authorization header only — never in a query parameter, where it would end up in access logs, browser history and referrer headers. Full API description.
